# Privacy Policy: Theme Studio for GitHub

Last updated: 3 November 2026

Theme Studio for GitHub ("the extension") restyles github.com and gist.github.com with themes, background
scenes, effects and sounds that you choose.

**In short: the extension does not collect, transmit or share any data about you.**

## What the extension stores

* Your settings (selected theme, custom themes, and the look, effect and sound options) are saved with
  `chrome.storage.sync`. If Chrome Sync is turned on, Chrome syncs them across your devices through your
  Google account. The developer cannot see them.
* An optional wallpaper image that you choose is saved with `chrome.storage.local`, on your computer only.

## What the extension does not do

* It does not collect personal information, browsing history, repository data, access tokens or the content
  of GitHub pages.
* It does not record your clicks or key presses. It reacts to clicks and to the state of the page on
  github.com and gist.github.com only to decide which effect or sound to play, and it keeps nothing.
* The extension itself makes no network requests. There is no analytics, no tracking, no advertising, no
  remote code and no remote fonts (the interface font is bundled with the extension).
* It does not sell, share or transfer data to anyone.

## Permissions

* `storage`: saves your settings, as described above.
* `scripting`: applies the theme to GitHub tabs that were already open when you installed the extension.
* Access to `https://github.com/*` and `https://gist.github.com/*`: needed to restyle those pages. The
  extension does not run on any other site.

## Changes and contact

If this policy changes, the new version will be posted here with a new date. For questions, open an issue at
https://github.com/ASNR1010/theme-studio-for-github/issues.
